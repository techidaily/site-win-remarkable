## MAJOR WARNING: Preserve DEX Cu 3 & LYRX Performance, Skip macOS Catalina Update!

[![Do not update to macOS Catalina](https://i1.wp.com/pcdj.com/wp-content/uploads/2019/10/no-to-catalina.jpg?resize=706%2C321&ssl=1)](https://i1.wp.com/pcdj.com/wp-content/uploads/2019/10/no-to-catalina.jpg?fit=706%2C360&ssl=1 "Do not update to macOS Catalina")

**Attention DEX 3 (all versions) and LYRX users: macOS Catalina (10.15) is not supported at this time.** 

If you upgrade to **macOS Catalina** you will be unable to properly launch DEX 3 (or LYRX). With Catalina, Apple has removed much of the OpenGL framework, which is the framework DEX 3 uses for accessing the GPU/graphics card. DEX 3 utilized OpenGL to render not only video, effects, overlays, and shaders, but also the DEX 3 GUI itself.

This is an architectural change to the macOS and will require significant changes to DEX 3’s (all versions) code base. PCDJ development is working diligently to address the changes macOS Catalina brings in our DJ software code-base, and we hope to release a free update in the next few weeks. In the meantime, avoid updating your live performance MAC to Catalina.

There are also significant changes to how iTunes (now separated into multiple applications, with “Music” as the new music-specific app) works in the new macOS, including the readable library file DEX 3 utilizes to showcase playlists in the browser. We are also working to support the new Music (app) library protocols.

When an update is ready for DEX 3 and/or LYRX that supports macOS Catalina you will be notified by email.

If you have a support inquiry regarding any of the above information you can submit a [ticket for PCDJ support](https://tools.techidaily.com/pcdj/products/).
