## Unveiling Lyrx: The Ultimate Mac-Exclusive Karaoke Programming Tool

[![](https://i2.wp.com/pcdj.com/wp-content/uploads/2015/04/lyrxpressrelease-coverimage.jpg?resize=530%2C298&ssl=1)](https://i2.wp.com/pcdj.com/wp-content/uploads/2015/04/lyrxpressrelease-coverimage.jpg?fit=530%2C298&ssl=1 "lyrxpressrelease-coverimage")

**Digital 1 Audio launches LYRX, Karaoke software designed exclusively for MAC that allows users to host karaoke with standard karaoke files as well as HD karaoke videos.**

[![](https://i2.wp.com/pcdj.com/wp-content/uploads/2015/04/lyrx-logo-web.png?fit=300%2C69&ssl=1 "lyrx-logo-web")](http://www.lyrxkaraoke.com)

Clearwater, Florida, 4/8/15\. Digital 1 Audio, Inc ([http://www.lyrxkaraoke.com](http://www.lyrxkaraoke.com/)), the premier creator of professional and consumer DJ software and karaoke software products, launched LYRX – an easy-to-use karaoke software platform designed exclusively for MAC. LYRX is karaoke show hosting software that supports all standard karaoke file types as well as HD video formats, and it’s truly fun to use.

[![](https://i2.wp.com/pcdj.com/wp-content/uploads/2015/04/MacBook_Pro_singer-main.png?fit=300%2C162&ssl=1 "MacBook_Pro_singer-main")](http://www.lyrxkaraoke.com)

_“We thought it was time that somebody make a high-quality MAC karaoke product for everyone that does computer karaoke”_ says Digital 1 Audio’s General Manager Ryan Sherr. _“LYRX is built on our professional software backbone and 16 years of entertainment software development experience, and it’s a truly a blast to use. LYRX is robust; throw all your MP3+G, Zipped MP3+G and Video Karaoke collection at it and it won’t skip a beat as the file browser will nimbly handle over 1 million songs”_ Sherr Continues _“You have all the standard features a pro KJ would want, such as a singers list and key control, but home users are really going to love the addition of microphone support and the ability to record their vocal performance overtop the playing karaoke track. LYRX fills a need in the market with very little in the way of karaoke software available to karaoke enthusiasts using MAC computers.”_

**Here are some of the notable features in LYRX – Karaoke Software For MAC:**

* LYRX Supports These High-Quality Karaoke File Types: MP3+G, Zipped MP3+G, WAV+G, and all Video Karaoke formats such as MP4.
* Send Lyrics Output To Secondary Display (Full Screen)
* Robust Music File Browser With Lightning-Quick Search and iTunes library support
* Simple Singers List For Singer Rotation Management (Displays next 3 singers on singers screen)
* MIC Support With Vocal Recording
* Low Latency Control with Support for Core Audio
* Built in 3 Band EQ
* Dynamic Resizing Graphics That Fit Any Display, With Retina Display Support

LYRX manufacturer’s suggested retail price is $39.95

**For more product information and a free evaluation version of LYRX please visit: <http://www.lyrxkaraoke.com>**

**Recommended System Requirements:**   
MAC: OSX 10.7.5 or higher  
2.5GHz Intel Core 2 Duo / Core 2 Quad / Core i3/i5/i7 /  
4 GIG RAM or Better  
Video card: Dedicated graphics card or Intel HD 3000 series card (or better)  
Mac: Multichannel Core Audio soundcard (for better MIC support)  
200 MB free on the hard-drive
